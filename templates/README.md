# Reusable working templates

Copy a template into your personal `astra/work/<your-name>/` directory, rename it for the story, and fill it with actual evidence. Templates intentionally contain prompts rather than completed answers. Application-specific docs belong on the application's contribution branch when the story calls for them.

| Template | Use |
| --- | --- |
| [Baseline](baseline.md) | Setup, versions, and pre-change checks |
| [User story](user-story.md) | Turn an outcome into a scoped assignment |
| [Pull request](pull-request.md) | Present a concrete change for review |
| [Review](review.md) | Ask and resolve behavior-focused questions |
| [ADR](adr.md) | Record a meaningful design decision |
| [Debug log](debug-log.md) | Reproduce, investigate, and explain a failure |
| [Learning journal](learning-journal.md) | Recall concepts and record assistance/evidence |
| [Weekly plan](weekly-plan.md) | Choose a manageable outcome and review it |
| [Capstone proposal](capstone-proposal.md) | Define a graduation project before building |
